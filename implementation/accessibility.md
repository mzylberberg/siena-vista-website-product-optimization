# Accessibility Implementation

## Objective

Improve the accessibility and usability of the Siena VISTA website by identifying and addressing content and structural issues that could create barriers for users.

## Accessibility Framework

The accessibility review was informed by the **Web Content Accessibility Guidelines (WCAG) 2.1**, an internationally recognized set of guidelines for improving web accessibility.

[WCAG 2.1 — W3C](https://www.w3.org/TR/WCAG21/)

## Evaluation Tool

The **WAVE Web Accessibility Evaluation Tool** was used to evaluate website pages and identify accessibility-related issues requiring further review.

[WAVE Web Accessibility Evaluation Tool](https://wave.webaim.org/)

WAVE was used as an evaluation aid rather than as a standalone measure of accessibility compliance. Automated tools can identify many potential issues, but accessibility also requires human review and contextual evaluation.

## Audit Approach

Accessibility was reviewed alongside content, readability, and website quality.

The review focused on:

- Alternative text for images
- Heading structure
- Content organization
- Readability
- Other accessibility-related content issues identified during page review

## Key Actions

- Identified images missing alternative text.
- Reviewed heading structure for consistency and hierarchy.
- Flagged accessibility-related content issues.
- Corrected identified issues within the available CMS editing scope.
- Incorporated accessibility considerations into broader content and website improvements.

## Results

The project identified **38 images missing alt text** and flagged heading-structure issues across the five audited pages.

The KPI dashboard records **4 accessibility issues completed** during the project.

## Scope

The accessibility work focused on frontend/CMS editing and content-level improvements.

It did not include backend development, custom code remediation, or a formal third-party accessibility certification.
