## 🎯 The Challenge

The Siena University VISTA program operates between **AmeriCorps** and the **nonprofit organizations where VISTAs serve**.

This created a multi-organization user journey in which prospective and incoming VISTAs could interact with AmeriCorps, Siena, and their host organization at different stages of recruitment and service.

### The Problem

User feedback revealed that the Siena VISTA website was not consistently functioning as a visible and useful touchpoint throughout the recruitment journey.

Prospective VISTAs could interact primarily with AmeriCorps and their prospective host organization without consistently encountering or returning to the Siena VISTA website.

A second challenge was **unclear program structure**. Some users did not immediately understand Siena's role in their VISTA experience or recognize that accepting a position involved engagement with both their nonprofit host site and the Siena VISTA program.

The challenge was therefore not simply:

> **"How do we make the website better?"**

It was:

> **"How can the Siena VISTA website become a useful, recurring touchpoint that helps prospective and incoming VISTAs discover opportunities, understand the program structure, and stay connected to Siena throughout their VISTA experience?"**

---

## 👥 User Research

I conducted user research using a Google Forms-based questionnaire to understand how users navigated the website, what information they expected to find, and where they experienced friction.

### Key Findings

Two recurring themes emerged:

**1. Low website visibility**

Users did not consistently encounter or return to the Siena VISTA website during the recruitment process.

**2. Unclear role of Siena**

Because the VISTA experience involved multiple organizations, some users were unclear about Siena's role and did not immediately recognize that their service included both:

**Nonprofit Host Site Responsibilities**  
+  
**Siena VISTA Program Engagement**

This created a visibility and communication gap across the user journey:

**AmeriCorps → Siena VISTA → Nonprofit Host Site**

### Product Insight

The problem wasn't simply:

> "Users can't find information."

It was:

> **"The website was not consistently positioned within the user's journey or providing enough value to become a recurring resource."**

This shifted the project from website maintenance toward **product optimization**.

## 💡 Product Opportunity

The research identified an opportunity to reposition the Siena VISTA website from a primarily informational/marketing resource into a more active product within the VISTA journey.

### Key Opportunity Areas

**Increase Visibility**  
Create stronger opportunities for prospective VISTAs to encounter the website during recruitment.

**Create Recurring Value**  
Give users practical reasons to return to the website throughout their VISTA experience.

**Clarify Siena's Role**  
Help users understand how Siena, AmeriCorps, and their host organization fit together.

**Improve Discoverability**  
Make important recruitment and program information easier to find.

### Key Product Decision: Open Positions

One of the primary product changes was the creation of an **Open Positions** page.

The page was designed to:

- Surface available Siena VISTA opportunities
- Create an earlier recruitment touchpoint
- Give prospective VISTAs a concrete reason to visit the website
- Allow users to apply directly through the Siena website
- Connect position information with the broader Siena VISTA program

### Intended User Flow

**Discover → Explore → Understand → Apply**

The Open Positions page was therefore not simply a new webpage. It was a product response to the visibility problem identified through user research.
