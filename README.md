## 🎯 The Challenge

Siena University's VISTA program operates as an intermediary
between AmeriCorps VISTA and the nonprofit organizations where
VISTAs serve.

User feedback revealed a visibility problem:

**Incoming VISTAs did not consistently use the Siena VISTA website
throughout the recruitment process.**

The challenge was therefore not simply improving the appearance
of the website.

The larger product question became:

> **How can the Siena VISTA website become a recurring resource
> throughout the VISTA recruitment and service journey?**

---

## 👥 User Research

I conducted user research using a Google Forms-based questionnaire
to understand how users navigated the website, what information
they expected to find, and where they experienced friction.

### Key Finding

Because Siena operates between the national AmeriCorps website
and individual nonprofit host sites, users could move through
the recruitment process without consistently returning to the
Siena VISTA website.

This created a visibility gap:

**AmeriCorps → Siena VISTA → Nonprofit Host Site**

### Product Insight

The problem wasn't simply:

> "Users can't find information."

It was:

> **"Users don't have enough reason to return to the website
> throughout their journey."**

This shifted the project from website maintenance toward
product optimization.

---

## 🔎 Pain Points

1. Low visibility during the recruitment journey
2. Confusion through the recruitment process as
3. Users did not naturally return to the website
4. Information discoverability could be improved
5. Some content was outdated or unclear
6. Accessibility issues created additional friction
7. SEO limitations reduced discoverability

---

## 🛠️ Product Improvements

### Content
- Rewrote unclear content
- Updated outdated information
- Improved information organization

### SEO
- Audited five pages
- Improved metadata
- Identified search visibility issues
- Measured before/after performance

### Accessibility
- Utilized [Web Content Accessibility Guidelines (WCAG) 2.1](https://www.w3.org/TR/WCAG21/) to implement changes that match an internationally recognized industry standard
- Audited image alt text
- Identified heading structure issues
- Addressed accessibility barriers

### User Experience
- Improved information hierarchy
- Improved discoverability
- Reoriented content around the VISTA journey
- Built an Open Positions page so VISTA's can apply directly through our website

### Governance
- Created a structured issue-tracking process
- Categorized website issues
- Established measurable KPIs

---

## 📈 Results

The project identified **84 website issues** and completed **80**,
with 4 remaining in progress.

Across five audited pages:

- Average SEO score improved by **16 percentage points**
- 35 content issues were resolved
- 26 readability issues were resolved
- 4 accessibility issues were resolved

## 🧠 Product Process

The project followed a continuous improvement model:

**Research → Diagnose → Prioritize → Implement → Measure**

Rather than treating the website as a static marketing asset,
I approached it as a digital product that should support users
through a specific journey.
